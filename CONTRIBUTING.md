# المساهمة | Contributing

## إضافة سياسة جديدة

1. أضف السياسة في مصفوفة POLICIES في docs/index.html
2. اتبع نفس الهيكل (عربي + إنجليزي + مراجع)
3. أضف رقم المعيار (CORF, NIST, ISO, CIS, CITRA)
4. حدد المؤسسات المستهدفة (gov, fin, priv, sme)

## Adding a New Policy

1. Add policy to POLICIES array in docs/index.html
2. Follow the same structure (Arabic + English + references)
3. Include standard references (CORF, NIST, ISO, CIS, CITRA)
4. Specify target organizations (gov, fin, priv, sme)
